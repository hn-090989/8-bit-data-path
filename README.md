# 8-Bit Computer / Datapath

## Overview

This project implements an **8-bit computer datapath** using digital logic components. It demonstrates the fundamental architecture of a processor by integrating registers, an Arithmetic Logic Unit (ALU), memory, instruction handling, and control signals into a functional digital system.

The circuit is designed to illustrate how data moves between different hardware components, how instructions are stored and processed, and how computational operations are performed within a processor.
The simulation was done on Proteas and project was implemented using discrete IC's.
